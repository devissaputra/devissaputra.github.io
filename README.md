# Devis Wawan Saputra Portfolio

This repository powers my current personal portfolio on GitHub Pages.

**Live site:** https://devissaputra.github.io/

The portfolio brings together three areas of work:

1. **Research**, including AI Engineering as a research area, academic research, applied R&D, and AI model evaluation.
2. **Learning & Development**, including learning systems, instructional design, curriculum architecture, academic program development, and quality assurance.
3. **AI in Education**, including research prototypes in generative AI, learning analytics, responsible AI, explainability, multimodal analytics, privacy, collaborative learning, and classroom discourse.

The site is intentionally lightweight and uses static HTML and CSS so the content remains easy to inspect, maintain, and publish through GitHub Pages.

## Main pages

`index.html` contains the academic and professional overview.

`research.html` contains research experience, degree research, applied R&D, and systems evaluation work.

`learningdevelopment.html` contains the Learning & Development project portfolio and supporting evidence.

`aieducation.html` contains the AI in Education research portfolio and links to the corresponding GitHub repositories.
